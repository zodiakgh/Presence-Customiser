Mon GitHub

Tout est personnalisable

Une interface simple pour les réglages courants, du JSON complet pour aller plus loin.

Profils et frames

Plusieurs profils, chacun avec des pages qui défilent, des images, des boutons, un groupe et un chrono ou compte à rebours.

Règles automatiques

Le profil change tout seul selon l'application active, l'heure, le CPU, l'inactivité ou une condition libre.

Variables en direct

{project}, {cpu|bar:10}, {spotify}, {time}… avec filtres et valeurs par défaut.

Plugins Python

Dépose un fichier .py dans le dossier plugins pour ajouter tes propres variables.

Confidentialité

Liste de processus et de mots à masquer : la présence bascule sur un profil neutre automatiquement.

Config en JSON

Importe, exporte et partage ta configuration complète. Barre système, démarrage avec Windows, thème.

Prêt en trois minutes

Discord doit être ouvert sur ton PC (application, pas navigateur).

Télécharge

Récupère PresenceCustomiser.exe dans les releases et lance-le.

Ajoute ton Client ID

Crée une application sur le portail développeur Discord, copie son Application ID dans les Réglages.

Active

Choisis un profil ou laisse les règles décider, puis clique sur « Activer la présence ».

Fais-en ta présence.
