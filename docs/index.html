Everything is customizable

A simple interface for everyday settings, full JSON when you want to go further.

Profiles and frames

Several profiles, each with rotating pages, images, buttons, a party size and a timer or countdown.

Automatic rules

The profile switches by itself based on the active app, the time, CPU, inactivity or a custom condition.

Live variables

{project}, {cpu|bar:10}, {spotify}, {time}… with filters and default values.

Python plugins

Drop a .py file in the plugins folder to add your own variables.

Privacy

List the processes and words to hide: the presence switches to a neutral profile automatically.

JSON config

Import, export and share your full configuration. System tray, launch with Windows, themes.

Ready in three minutes

Discord must be open on your PC (the desktop app, not the browser).

Download

Grab PresenceCustomiser.exe from the releases and run it.

Add your Client ID

Create an application in the Discord developer portal and paste its Application ID in Settings.

Enable

Pick a profile or let the rules decide, then click “Enable presence”.
